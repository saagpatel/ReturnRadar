# ReturnRadar 1.0.0 release notes (draft)

Status: source candidate only. No signed or notarized binary is represented by
this document, and no GitHub Release has been published.

## Highlights

- Track purchase return windows, rebates, and warranties in a local SQLite
  database.
- Review image and PDF receipts locally with macOS Vision and PDFKit.
- Require explicit correction, acknowledgement, and confirmation before a
  captured deadline is written.
- Keep raw receipt bytes, private filenames, and full OCR text out of persisted
  capture records.
- Receive duplicate-suppressed native notifications for supported existing
  deadline records.

## Supported platform

- macOS 13 Ventura or later.
- Universal build for Apple silicon and Intel Macs.
- Direct-distribution application and DMG are the intended release formats.

## Known limitations

- OCR and policy interpretation support bounded English phrases and require
  correction when evidence is missing, ambiguous, or low-confidence.
- Captured deadlines do not automatically create notifications or mutate an
  existing purchase, rebate, or warranty.
- ReturnRadar does not guarantee that a merchant policy is current or that a
  deadline establishes legal rights.
- Human acceptance was not performed for this source candidate.
